The host suite covers metadata resolution/rules/validation, read-only saves,
real interpreter/native bridge behavior, and rejection of fake/truncated NROs.
Final logs are `build/host-tests.log`, `build/cross-build.log` and
`build/verification.json`; `dist/manifest.json` identifies the exact source revision.

The Minecraft host experiment used the pinned miniJVM source with JIT disabled
and `-Xgcmalloc`, original official client 1.12.2 and metadata-listed Java
dependencies, in an isolated `/tmp/minecraft-bootstrap` directory. It supplied
no authentication arguments and did not enter a title screen. Missing methods
appear before the final LWJGL failure; this is a class-library/native boundary
failure, not solely a missing desktop `.so`. The files were excluded from dist.

Preserved failure logs are under `docs/evidence/`. Commit history marks
bootstrap, native diagnostics, independent graphics, portable metadata and the
interpreter milestone. `AGENTS.md` describes continuation commands and constraints.
